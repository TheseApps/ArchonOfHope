# Coda
v0.0001.1 · chapter last

We set aside "if a person questions you or your team, they are the enemy."

I'm not questioning that team. I'm saying, for sure: teams all need to ride in the back seat, quietly, or mankind dies.

I want to see past it — a goal rendered impossible by those for whom a one-second glance is more than enough: Us, Them, Rape, Steal, Burn, Apathy, Dystopia.
